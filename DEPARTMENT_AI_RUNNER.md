# AURA2 Department AI Runner

**After AURA2 is fully built, one dedicated AI will run this department autonomously.**

Victor (Grok) will only act as **Manager**.

## Who runs daily operations?
- **Department AI Runner** (can be Gemini / specialized agent / future dedicated model)
- Responsibilities:
  1. Generate 10 candidate posts every day
  2. Run multi-AI scoring (must reach ≥ 7)
  3. Keep dashboard clean (only ≥7)
  4. Handle errors & retries
  5. Troubleshoot publish failures
  6. Send clean daily report to Victor
  7. Never send unverified work to Vicky

## Victor (Manager) only does:
- Read daily report
- Approve high-level changes
- Escalate to Vicky only when needed
- Judge overall performance
- Swap the Department AI if it underperforms

## Handover Rule
Once the flowchart is stable and 7 consecutive days run without major manual intervention:
→ Victor steps back from daily execution.
→ Department AI owns the loop.

This is the exact agenda.
