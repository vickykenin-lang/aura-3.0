# AURA2 Daily Operating Instructions

## Controlled-pilot cycle

1. Founder manually runs AURA2 Daily Content Generator.
2. Read the kill switch.
3. Generate exactly ten candidates from the curated image pool.
4. Validate local copy structure.
5. Founder manually runs AURA2 Dual Quality Gate.
6. Inspect every actual image with Gemini Vision.
7. Send only visual passes to DeepSeek.
8. Update gate results and dashboard data.

## Founder cycle

1. Review the dual-gate queue.
2. Normally select only one or two best candidates.
3. Submit the generated GitHub issue.
4. Check that the Action records approved_manual.
5. Publish manually on Instagram and record the verified media reference.
6. Record inquiries and follow-up outcomes.

## Non-negotiable rules

- Never bypass the dual gate.
- Never treat a commit message as publication proof.
- Never expose secret values.
- Never claim reference media as completed Design Infra work.
- Never conceal a failed Action.
- Stop publication when the kill switch is on.

Use OPERATIONS_RUNBOOK.md for failures and recovery.
