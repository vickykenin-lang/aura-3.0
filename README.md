# AURA3

Governed content-to-qualified-lead department for Design Infra.

Founder authority is final. Production, approval, publishing, and business-outcome evidence remain separately governed.

## Media flow

Static image posts remain on the Founder Approval Center. Founder may separately trigger an interior walkthrough Reel from an eligible image. Reel generation is a distinct backend program, while all generated Reel previews and Founder Reel decisions are consolidated in the existing `reels.html` dashboard tab. No separate video dashboard is used.
