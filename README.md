# AURA 3.0 — Founder-Governed Creative Studio

AURA 3.0 is Design Infra's standalone, self-operating content studio. It can research, generate, transform and prepare content internally; the Founder remains the final authority for dashboard approval and public publishing.

## Authority hierarchy

Founder → AURA 3.0 → core agents → qualified providers and executors.

Providers and GitHub Actions are replaceable implementation components. They do not define AURA 3.0 identity or authority.

## Core agents

- **Interior Designer** — automatically researches and prepares interior content; also accepts Founder-supplied images through the dashboard.
- **Vastu Consultant** — runs automatically without routine input and prepares Vastu image posts.
- **Creative Bench** — stays available for Founder idea prompts and creates image or Reel candidates.
- **Shared Media Branch** — supports image enhancement, image-to-3D, Reel generation, and sound or voice for all agents.

## Approval and publishing

All candidates appear on the dashboard for Founder review. Only the Founder can approve, reject, or publish to Instagram. Internal autonomous work never implies permission for public release.

## Victor scope

Victor is not active in AURA3 governance, approval, or publishing. A future integration may allow Victor only to submit an idea prompt to the Creative Bench.
